## 🚀 Key Features

- **Futuristic Cyber Aesthetics**: Dark space canvas (`#030014`), violet and neon cyan gradients, glowing glassmorphism cards, and interactive canvas particles with quantum entanglement lines.
- **Interactive Quantum Playground**:
  - Live 2.5D **Bloch Sphere visualizer** with polar angle ($\theta$) and phase ($\phi$) sliders.
  - Dirac bra-ket state calculation: $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$.
  - Quantum measurement simulator implementing Born's rule with animated wave-function collapse.
  - **Quantum Gates Lab**: Apply Hadamard ($H$), Pauli-X, Pauli-Z, and identity transformations to live circuit wires.
  - **Bell State Entanglement Lab**: Simulate spooky action at a distance ($|\Phi^+\rangle = \frac{|00\rangle+|11\rangle}{\sqrt{2}}$) with correlated measurement probability tracking.
  - Quantum micro-quiz to test intuition.
- **Interactive Scope & Timeline Configurator**: Studio clients can configure system category, SLA scale, and timeline speed to receive live squad recommendations.
- **Interactive Command Terminal (`Ctrl+K`)**: Futuristic developer drawer with commands (`help`, `authors`, `courses`, `studio`, `quantum`, `entangle`, `status`, `clear`).
- **Dual-Mode Enquiry & Enrollment Portal**: Integrated demonstration forms with ticket reference generation and FAQ accordion.

## ⚡ Deployment to Vercel

The application is pre-configured for instant zero-configuration deployment to **Vercel**:

### Option 1: Vercel CLI
```bash
npm install -g vercel
vercel
```

### Option 2: GitHub / Git Provider
1. Push this repository to GitHub or GitLab.
2. In the [Vercel Dashboard](https://vercel.com/new), click **Add New Project** and import the repository.
3. Framework Preset will automatically detect **Vite**.
4. Root Directory: `./`
5. Build Command: `npm run build`
6. Output Directory: `dist`
7. Click **Deploy**.

`vercel.json` is already included to manage client-side single-page routing seamlessly.
